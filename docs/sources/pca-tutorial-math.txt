Q1. Perform Principal Component Analysis on the following data set using the following
guidelines ​
   (i) Preprocess the data using Mean Normalization, with NO data Scaling / Feature Scaling. ​
   (ii) Find the principal components along with the data variances along them.​
   (iii) Reduce dimensionality to keep at least 95% variance of the original data set.​
   (iv) Recast/Reduce the data points along the principal component(s), keeping at
         Least 95% variance of the Original data set.​
    (v) Reconstruct the original data points from the reduced dimensional
         representation / PC-axis representation and find the mean absolute errors
         (MAE), Sum of Squared Errors (SSE) and Root Mean Squared Error (RMSE) for
          the data set. {RMSE = square root of Mean of Squared Error}​

      Data Set: { (2.5, 2.4), (0.5, 0.7), (2.2, 2.9), (1.9, 2.2), (3.1, 3.0), (2.3, 2.7),
                  (2.0, 1.6), (1.0, 1.1), (1.5, 1.6), (1.1, 0.9) }​
