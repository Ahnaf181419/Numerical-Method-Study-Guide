LU Decomposition (contd.)
• Decompose a Non-Singular Square Matrix into LU form
• For a non-Singular Matrix A, 𝑑𝑒𝑡𝐴 ≠ 0
• L is the lower triangular matrix (Elements above diagonal are zero)
• U is the upper triangular matrix (Elements below diagonal are
  zero)

Why do we need LU Decomposition?
When the solution vector {B} changes but the coefficient matrix [𝐴]
is fixed, it is costly to repeat elimination method each time.

LU decomposition allows us to decompose 𝐴 into [ L] and
[𝑈] 𝑜𝑛𝑐𝑒. Then, for each new solution vector, we only need to
perform forward and backward substitution, while 𝐿 and
[𝑈] remain fixed.

It is very useful for calculating the inverse matrix

Steps of LU Decomposition Method
      [A] {x} = {b}

    [L] [U] {x} = {b}

     [L] {d} = {b} ……..(1) [Assuming, [U]{x} = {d}]

From eqn 1, we will get {d} using Forward Elimination
    [U] {x} = {d} ……..(2)
From eqn 2, we will get {x} using Backward Substitution
